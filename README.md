# CVC_Assigment2
This 2nd assigment is focused on Object Recognition and Image Retrival using handcrafted descriptors and self-supervised/vision-language representations.

The main objective is to build and evaluate image classifiers and retrieval systems using handcrafted local features, pretrained visual representations, and image-text similarity. It will as be analyzed their accuracy, data efficiency, robustness and computation cost using a common evaluation protocol.
